EXTENDED KEYBINDS
INPUT WHEN GAME UNFOCUSED
Keeps your HOTAS live while another window (like this page's browser) has focus. Turn this ON if you run the MFD in a browser on the same PC as the game — otherwise the game must stay focused for the stick to work, which throttles the browser in the background and makes the MAP cursor stutter. Leave OFF for a tablet or phone, where the game keeps focus anyway. While ON, your stick still flies the aircraft even while you're clicking around in another window.
FUNCTIONKEYBOARDJOYSTICK / HOTAS
Each setting only changes what a freshly-spawned aircraft starts with; the binds above always work regardless of these.
RADAR ON ON START
Radar starts ON when spawning in a new aircraft (the game's own default). Turn OFF for more immersion: radar starts off, arm it yourself.
ENGINE ON ON START
Engine starts ON when spawning in a new aircraft (the game's own default). Turn OFF for more immersion: engine starts off, start it yourself.
MASTER ARMS ON ON START
Master Arms starts ON (unrestricted, today's behaviour) when spawning in a new aircraft. Turn OFF for more immersion: weapons/countermeasures are blocked until you arm.
