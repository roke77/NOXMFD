# TGT

Target-selection filter mirroring the in-cockpit TARGET SELECTION panel: toggle which factions,
categories, and vehicle types can be targeted (plus LASER/HUD), with RESET and CLEAR, above your
live selected-target list. A DATALINK button bulk-deselects the datalink-only locks; a STALE
button bulk-deselects locks whose relayed position the game no longer trusts (the same check
behind the TGP's own "?" marker).
