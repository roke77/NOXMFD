# HUD

A remote for the game's in-cockpit HUD OPTIONS: mode tabs (NAV/GUN/A2A/…) and per-category /
per-type toggles for which unit icons show on the HUD, plus a declutter strip that hides native
HUD widgets — the weapon panel, corner minimap, and boxed flight readouts.

Reached from MAIN via **CFG** in either layout, alongside [KEY](keybinds.md),
[LYT](layouts.md), and [RTS](rates.md).
